## How to Use Both Modes

### Scenario 1: Quick Demo (Use Automated Mode)

```bash
# 1. Initialize
python -m ai_employee init

# 2. Create task
echo "Research AI tools" > ai_employee_vault/Inbox/task.txt

# 3. Process (fast)
python claude_runner.py

# 4. Check results
ls ai_employee_vault/Done/
```

**Result:** Task processed in < 1 second with pattern-based plan

### Scenario 2: Real Work (Use Claude Code Mode)

```bash
# 1. Start Claude Code
claude

# 2. Navigate
cd silver-tier

# 3. Create complex task
cat > ai_employee_vault/Inbox/analysis.txt << 'EOF'
Analyze our Q1 2026 customer feedback data.
Identify top pain points, feature requests, and sentiment trends.
Create actionable recommendations for the product team.
EOF

# 4. Process with AI
python claude_runner_with_ai.py

# 5. Claude Code will:
#    - Read and understand the task
#    - Use AI reasoning to analyze
#    - Generate intelligent, context-aware plan
#    - Make smart routing decisions
```

**Result:** High-quality, context-aware plan generated by real AI

### Scenario 3: Production (Use Both)

```bash
# Setup Task Scheduler for automated mode
# Runs every 15 minutes: python claude_runner.py

# Manually process important tasks with Claude Code
# When you see complex task: python claude_runner_with_ai.py
```

## Architecture

### Automated Mode Flow
```
claude_runner.py
    ↓
IntegratedRunner
    ↓
FileWatcher + GmailWatcher (capture tasks)
    ↓
ReasoningSkill (pattern matching)
    ↓
ApprovalSkill (if needed)
    ↓
MCPServer (execute)
    ↓
Done/
```

### Claude Code Mode Flow
```
claude_runner_with_ai.py
    ↓
Generates prompt for Claude Code
    ↓
Claude Code CLI
    ↓
Claude AI reasoning
    ↓
Generates intelligent plan
    ↓
Determines routing
    ↓
Waiting_Approval/ or Done/
```
